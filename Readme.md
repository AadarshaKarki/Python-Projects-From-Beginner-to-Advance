# Simple Currency Converter 💱

A beginner-level Python project that converts an amount from one currency to another using live exchange rates.

## Features

- Converts between any currency code (e.g., USD, EUR, INR, GBP)
- Uses free, daily‑updated exchange rates from the European Central Bank
- Interactive command‑line interface – just type your amount and currency codes
- No sign‑up or API key needed

## Requirements

- Python 3.6 or higher
- The `CurrencyConverter` library

## Installation

1. **Clone or download** this repository.
2. **Install the required library**:
   pip install CurrencyConverter
